# معرض قاصد كريم للإضاءة الفاخرة | KASED KARIM LIGHTING - الشيخ زايد

موقع إلكتروني بريميوم وواجهة رقمية فائقة الفخامة لمعرض **Kased Karim** في **الشيخ زايد**، مُصمم خصيصاً لأصحاب الذوق الرفيع، مقتني القصور والفيلات، ومهندسي الديكور والتصميم الداخلي.

## 🎨 هوية الألوان المعتمدة (Design Tokens)

تم تطبيق نظام الألوان المحدد بالكامل داخل ملف `css/style.css` بدقة هندسية:

```css
:root {
  --bg-primary: #F0F4F8;       /* الخلفية الأساسية المريحة للعين */
  --bg-surface: #FFFFFF;       /* كروت المنتجات لتبرز فوق الخلفية بفخامة */
  --text-main: #0F172A;        /* العناوين والنصوص الداكنة الراقية */
  --text-muted: #64748B;       /* النصوص الفرعية والمواصفات */
  --border-light: #E2E8F0;     /* الفواصل الناعمة */
  --accent: #F59E0B;           /* أزرار الـ Action والعروض ولمسات الذهب */
}
```

## ✨ اللمعة الفضية السريعة الخاطفة وفونت Archivo Black

في وسط الواجهة الرئيسية للموقع، يبرز اسم المعرض:
**`KASED KARIM`**
بخط **`Archivo Black`** ذي الطابع العصري الجريء، مع شعاع **لمعة فضية سريعة وخاطفة** تعبر الكلمة بشكل دوري وسلس:

- نوع الخط: **`Archivo Black`**
- اللمعة: لمعة سريعة نقية (`fastSilverGlint`) بدون أي تموجات جراديانت بطيئة على النص.
- **الشريط الرئيسي (الهيدر):** تم حذف أي لمعة منه تماماً ليبقى ثابتاً، رصيناً، وأكثر وضوحاً في التصفح (`color: #0F172A`).

## 🏛️ أقسام ومزايا الموقع الرئيسية

1. **الواجهة الرئيسية (Hero Section):**
   - اسم المعرض في المنتصف بخط Archivo Black ولمعة الفضة المتحركة.
   - إضاءة بؤرية خلفية تحاكي كشافات المعارض العالمية.
   - مؤشرات الثقة (15 عاماً من الخبرة، +2500 مشروع فيلا وقصر في زايد وأكتوبر، ضمان 5 سنوات).

2. **كتالوج ومتجر وحدات الإضاءة (Showroom Catalog):**
   - فلترة حسب التصنيف: ثريات ونجف فاخر، مسارات مغناطيسية، إضاءات جدارية Sconces، أباجورات ومصابيح طاولة، إضاءة لاندسكيب وخارجية، بروفايل ليد ذكي Trimless.
   - بحث فوري وترتيب حسب السعر والأحدث.
   - كروت منتجات بارزة بخلفية بيضاء (`#FFFFFF`) وظلال سينمائية.

3. **نافذة المواصفات الفنية التفصيلية (Quick View Modal):**
   - أبعاد القطعة، الخامات والتشطيب، الاستهلاك (Wattage)، معامل الألوان (CRI > 97)، والفولت، مع معرض صور وإضافة فورية للمقايسة أو استفسار فوري عبر واتساب.

4. **سلة المقايسات الرسمية (Quotation Drawer):**
   - تجميع المنتجات المطلوبة وحساب إجمالي السعر التقديري بالجنيه المصري (EGP).
   - زر إرسال المقايسة الجاهزة مباشرة لواتساب مهندس المبيعات بالمعرض.

5. **خدمات الاستشارات المعمارية (DIALux Lighting Design):**
   - مخططات هندسية، أنظمة سمارت، وتفصيل ثريات الأسقف المرتفعة (Double Height).

6. **معرض الشيخ زايد والتواصل المباشر:**
   - عنوان المعرض على محور وصلة دهشور، مواعيد العمل، وزر التواصل المباشر مع المعرض والاتجاهات على الخريطة.

## 🛠️ كيفية إضافة وتعديل وحدات الإضاءة مستقبلاً

تم تصميم الكتالوج ليكون مرناً للغاية وبطريقتين:

### الطريقة الأولى: من خلال واجهة الموقع مباشرة (بدون كود)
1. افتح الموقع واضغط على زر **"إضافة وحدة"** في الشريط العلوي.
2. اكتب اسم الوحدة، السعر، التصنيف، الأبعاد ورابط الصورة.
3. اضغط **"حفظ وعرض الوحدة بالمعرض الآن"**.
4. ستظهر الوحدة فوراً في المتجر ويتم حفظها في المتصفح، وسيظهر لك الكود جاهزاً في المربع الأسفل إن أردت نسخه.

يمكنك فتح ملف `js/data.js` وإضافة أي وحدة جديدة داخل مصفوفة `INITIAL_PRODUCTS`:
